# Android Compatibility & Rebuild Toolkit
A collection of tools for **rebuilding, patching and optimizing Android applications** for Windows Subsystem for Android (WSA).

### What it does
Handles **APK decoding, smali modifications, native ARM64 patching, JNI compatibility fixes, OpenGL optimizations**, rebuilding and signing.

Uses **application-specific profiles** to keep the tooling reusable across different builds. Includes utilities for **memory analysis, runtime diagnostics and reverse engineering**.

### Requirements
**Python 3** · **Java** · **Apktool** · **Android SDK Build Tools**
